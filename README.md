# Ferramenta Interativa de Estudo

## Descrição
Uma aplicação web para ajudar estudantes a revisar conteúdos,
criar resumos, montar flashcards e testar conhecimentos com um quiz.

## Funcionalidades
- Gerar um resumo automático a partir de um texto.
- Identificar palavras-chave.
- Criar cartões de perguntas e respostas.
- Navegar entre flashcards.
- Responder a perguntas de múltipla escolha.
- Visualizar a pontuação do quiz.

## Tecnologias utilizadas
- HTML5
- CSS3
- JavaScript

## Como executar
1. Abra o arquivo `index.html` em um navegador.
2. Digite ou cole um texto para gerar um resumo.
3. Crie flashcards para revisar o conteúdo.
4. Responda ao quiz para testar seus conhecimentos.

## Publicação no GitHub Pages
1. Envie o arquivo `index.html` para o repositório.
2. Acesse Settings > Pages.
3. Em Build and deployment, selecione Deploy from a branch.
4. Selecione a branch `main` e a pasta `/root`.
5. Salve e aguarde a publicação.

## Objetivo
Desenvolver uma ferramenta interativa que facilite a organização
e a revisão de conteúdos de estudo.
